# Security Policy

## Supported Versions

We actively support and maintain the latest version of this project.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it responsibly:

1. **Do not create a public GitHub issue.**
2. Report vulnerabilities privately via [GitHub Security Advisories](https://github.com/wliu415/workspace-gmail-assistant/security/advisories/new).
3. Provide detailed steps to reproduce the vulnerability, including sample code and environment configuration if applicable.

We will review your submission promptly and work with you to resolve the issue before public disclosure.
